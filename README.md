# 📈 Is It Time to Buy Something Other Than Index Funds?

**NEJ!** (That's Swedish for "NO!")

A humorous single-page website that answers the eternal investor question: *"Är det dags att köpa något annat än index?"* (Is it time to buy something other than index funds?)

## 🌐 Live Site

Visit the site at: [ärdetdagsattköpanågotannatänindex.info](http://xn--rdetdagsattkpangotannatnindex-zpcxx17c.info/)

## 🎯 Purpose

This project provides a definitive answer to anyone considering abandoning their passive index fund investment strategy. Spoiler alert: the answer is always **NEJ!**

Each visit displays a randomly selected, sophisticated-sounding financial explanation for why active fund management or individual stock picking is generally not recommended over passive index investing.

## ✨ Features

- **Clear Answer**: A big, bold "NEJ!" to cut through the noise
- **Random Financial Wisdom**: Sophisticated-sounding explanations in Swedish
- **Responsive Design**: Works on all device sizes
- **Modern Typography**: Clean Roboto font for readability
- **Subtle Animations**: Smooth entrance effects
- **Fun Confetti Effect**: Click the answer for a celebratory surprise!

## 🛠️ Technology

This is a simple static site using:
- Pure HTML5 & CSS3
- Vanilla JavaScript
- Google Fonts (Roboto)
- Google Analytics for tracking
- GitHub Pages for hosting

## 🚀 Deployment

The site is automatically deployed via GitHub Pages when changes are pushed to the main branch. The custom domain is configured in the `CNAME` file.

## 🤔 Why Index Funds?

Index funds offer several advantages for most investors:
- Lower fees compared to actively managed funds
- Broad market diversification
- Historically strong long-term performance
- Simplicity and transparency
- No need to "beat the market"
